# 素材来源与制作说明

本文件说明《定风波：风雨有时，脚步由你》V2 工程中的文字、物件、纹理、声音和字体来源。

## 文字与视觉参考

- 原词及小序：苏轼《定风波·莫听穿林打叶声》。画面引用“莫听穿林打叶声”“何妨吟啸且徐行”等原词，纸稿引用小序；1082 年、黄州与沙湖道中遇雨作为词作的历史背景。
- 人生哲理文案：为本片创作的现代释意。“选择回应”“照顾自己”等属于现代解读，不作为苏轼的原话或内心独白。
- 视觉方向：用户提供的《运气的形状》分镜截图，用于参考暗色展台、金色图解、实体物件和动态排版。工程中的场景与图形为本片重新制作。

## 三维物件、图解与纹理

| 素材 | 来源与实现 |
|---|---|
| 三维雨滴、竹杖、芒鞋、蓑衣 | 本工程原创程序化几何；由 `Hero3D.tsx` 和 `models/geometry.ts` 定义，无外部下载模型 |
| 竹节、草鞋经纬、蓑衣纤维 | 由参数化曲线、网格及实例化几何构造；材质、反光和灯光在本地生成 |
| 开场折射雨滴及水波 | 场景代码中的原创 SVG 形状、渐变、线条形变和固定种子粒子 |
| 纸稿、金环、人生路径、天气波带 | 本片原创 SVG 与程序图形；关系图用于表现思想，不引用外部数据集 |
| 微尘、雨珠、溅水、金线光效 | 按帧计算的 Canvas 或 SVG 效果，随机参数固定种子 |
| `public/textures/grain.png` | 本工程生成的细颗粒纹理，用于暗部层次 |
| 封面 | 使用本工程的物件、排版和视觉系统组成 |

三维渲染采用 Three.js、React Three Fiber 和 Remotion ThreeCanvas。运行时不请求远程模型、在线字体或图库素材。依赖的开源组件许可随 npm 包保留，其具体版本见 `package-lock.json`。

## 音乐与拟音

**BGM：《算力小曲》**，由用户上传并指定用于本视频。工程文件为 `public/audio/bgm-original.mp3`，保留上传文件的原始内容。来源与使用范围依据用户提供的素材和本次制作要求；本说明不替音乐权利人授予额外许可。

原文件 SHA-256：

```text
ab1ebad4e3ced73fa0d7763e455f573976c243ff0b00e0b7e91a90a4e3debd05
```

混音取 BGM 前 120 秒，原速、原音高、零时间偏移；作整体配平、极短的音量让位和结尾淡出。声音制作与原速采样映射记录见 `public/audio/audio-v2-report.json`。

**物件拟音**包含 28 个主要声音事件，由 `scripts/audio_design_v2.py` 原创合成，包含水珠、竹杖接触、草鞋、草编摩擦、纤维收紧、纸张、短金属余音及空气层。脚本使用固定种子噪声、衰减振动模式、纤维颗粒和短反射；未使用外部音效库或旁白素材。

- `sfx-v2.wav`：独立拟音轨，供检查和重新混音。
- `soundtrack-v2.wav`：BGM 与原创拟音的完整双声道混音，48 kHz、24-bit PCM、120 秒。
- `README-V2.md`：声音设计、事件帧号与复现命令。
- `audio-v2-report.json`：音频测量、事件表、采样对应关系与文件校验值。

## 中文字体

`public/fonts/Serif.woff` 与 `Sans.woff` 为本地 Noto CJK 中文字体，分别用于诗句及主要文字、辅助说明。上游项目为 [Noto CJK](https://github.com/notofonts/noto-cjk)。字体使用 SIL Open Font License 1.1；版权、许可正文及随附发行说明保留在 [public/fonts/LICENSE.txt](public/fonts/LICENSE.txt)。

工程再分发时应一并保留字体文件对应的许可说明。

## 可复现范围

动画由指定视频帧决定，几何、粒子和原创拟音使用固定规则或固定随机种子；字体、音乐和纹理均包含在工程中。安装锁定依赖后即可在本地预览和导出。不同 Chromium、图形驱动或音视频编码器版本可能造成细微的像素或编码差异，文件校验值应针对实际导出的文件重新计算。
