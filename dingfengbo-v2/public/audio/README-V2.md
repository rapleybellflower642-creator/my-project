# 《定风波》V2 音乐与物件拟音

`soundtrack-v2.wav` 是可直接用于成片的完整双声道混音。不要同时叠加 `bgm-original.mp3` 或 `sfx-v2.wav`，以免重复播放。

- 精确 120 秒、48,000 Hz、双声道、24-bit PCM，共 5,760,000 个采样。
- 原BGM使用用户提供的《算力小曲》前 120 秒，原速、原音高、零时间偏移。
- BGM仅作音量处理：整体配平、十处不到 0.8 dB 的短暂让位，以及 118.6–120 秒余弦平方淡出。未重剪、拉伸或循环音乐。
- 无旁白；无外部下载音效。所有物件拟音均由同目录工程内脚本原创合成，随机种子固定为 `10822333`。
- `sfx-v2.wav` 是独立拟音轨，保留原混音前的音量，可用于单独检查和重新混音。
- `audio-v2-report.json` 包含实际响度、真峰值、SHA-256、完整事件表、每个事件与音乐的电平对比，以及原速采样映射证据。

## 声音设计

本版以可辨认的物件材质推进节奏。竹杖由四组短促非等比共振、石面接触和轻微回弹组成；草鞋分为鞋底触地、草编摩擦和随后落回的浅水；蓑衣用不规则粒子状摩擦表现纤维穿插，连续三次收紧。水珠使用短促液体共振及宽频接触；少量细金属余音用于金线和斜照，避免每个转场都发出相同提示音。

主落点接近画面中心，移动和早期反射在左右声道展开。室内般的短反射营造暗色物件展台的空间感，避免长混响覆盖节奏。环境层只在雨、纤维和微冷段短暂出现，响度明显低于前景物件。

## 可复现制作

在工程根目录运行：

```bash
python scripts/audio_design_v2.py
```

依赖 Python 3、NumPy、SciPy 与 FFmpeg。脚本只生成本版拟音、混音和验证报告，不改动原BGM。归一化采用两遍 EBU R128 测量，目标约−15 LUFS、真峰值不高于−1.5 dBTP；断言检查持续时间、采样数、声道、削波、末采样归零和音乐原速映射。

PCM交付混音的验证值以 `audio-v2-report.json` 为准。视频中的AAC编码应由最终成片验证再次测量，以覆盖有损编码带来的小幅真峰值变化。
