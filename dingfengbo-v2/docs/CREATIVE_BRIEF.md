# 《定风波》V2：物件图解动画制作说明

本文件说明 V2 工程的创作方向、文案、时间轴和当前视觉实现。视觉方向依据用户提供的《运气的形状》分镜截图，以暗色展台、实体物件、金线图解和动态排版展开。分镜与字幕的执行依据为 `src/v2/Film.tsx`、`src/v2/chapters/` 和本目录的 `TIMELINE.json`；本说明不代替最终成片的技术验证报告。

## 一、创意与风格

**片名：《定风波：风雨有时，脚步由你》**

核心问题：外界一直变化，一个人怎样找回自己的步调？

雨、竹杖、芒鞋、蓑衣、斜照被转化为可以观察变化的对象。贯穿全片的金色路径连接“选择回应—认真行动—承认感受—回望整合”。现代释意从苏轼词意出发，不虚构苏轼的心理独白，也不把一时低落或暂时晴朗写成对人生的最终判断。

各段以线条、接触点与物件意象相互呼应，通过章节切换和短光扫衔接。雨滴、纸稿、声纹、竹杖与蓑衣采用各自的场景组件；部分段落通过连续的线条生长、纤维聚合或透视变化完成推演。

形式为音乐、中文字幕与信息可视化，无旁白。主合成设为 120 秒，1920 × 1080，16:9，30 fps，共 3,600 帧。

## 二、视觉系统与技术实现

| 角色 | 色值 | 用途 |

三维竹杖、草鞋与蓑衣采用原创程序几何、材质和灯光。竹节、编织经纬与蓑衣纤维具有可辨认的结构；纸稿、声纹和关系图采用 SVG；微尘使用 Canvas。开场雨滴用 SVG 折射渐变与高光表现，以便精确控制接触点。末段天气空间以三维坐标投影到 SVG，形成层间遮挡、侧移与纵深展开。

统一文字布局由 `SceneShell.tsx` 定义：常规诗句 72 px，题名章节 100 px；“谁怕？”先以 177 px 出现，再收为章节标题；底部现代释意 46 px。片尾题名为 156 px，结语为 49 px。主体与辅助标签保留在字幕上方，底部字幕距画面底边 91 px。字体为本地 Noto CJK 衬线与无衬线字体。

暗底、金色细线、玉青回应路径与琥珀斜照分工明确。辉光用于光点、金线和局部反射，文字保持独立清晰。全片的随机粒子与程序素材使用固定规则或固定种子，视觉运动均由帧号驱动。

## 三、节奏与音乐

使用用户提供的《算力小曲》前 120 秒，保留原速、原音高与零时间偏移。原文件长 192.456 秒、48 kHz 双声道；文件校验值记录在 `TIMELINE.json`、音频报告及素材说明中。118.6–120 秒进行结尾淡出。

前 120 秒的自动瞬态分析得到约 **109.17 BPM**，参考周期约 **0.549608 秒**、网格起点约 **0.421043 秒**。18 秒和 105.94 秒附近的能量增强用于组织回应路径及最终空间展开，约 88 秒后减小动作与附加音效的密度。分析方法和数据见 `BGM_ANALYSIS.json`。

这些数值是节奏参考，不代表对每小节强拍的人工确认。约 2.2 秒的四拍动作单位用于安排接触、路径延伸、纤维收束和视角变化，字幕保持稳定的阅读窗口。章节边界按绝对帧号设定，避免逐拍取整造成累积漂移。

## 五、加强特效的方式

1. **接触具有来源。** 雨滴、竹杖和草鞋的接触点生成圈波与水珠，配合局部高光、阴影和小幅回弹。水珠落回地面后消失，避免进入底部字幕区。
2. **结构逐步展开。** 声纹稳定后才显示回应路径，物件接触后路径才生长，蓑衣由纤维聚合而成，天气空间由聚拢状态向纵深展开。
3. **布局与尺度变化。** 开场近景退远、纸稿与路径、声纹中心、左右比较、纤维聚合、回望路径和末段空间展开形成不同的构图节奏。
4. **光色承担意义。** 玉青用于自主回应，冷色用于风雨与微冷，暖琥珀用于斜照；末段让不同天气光色共存。
5. **保留强弱差异。** 开场接触、蓑衣编织和末段展开较强；“微冷”“回首”“归去”收敛动作与音效，标题和释意保持可读。

## 六、音效与混音

全片包含 **28 个主要声音事件**，另有低电平雨、纤维和风环境层。物件拟音由 `scripts/audio_design_v2.py` 原创合成，不使用外部音效库。接触与动作的绝对帧号写入 `public/audio/audio-v2-report.json`；摩擦或气流的少量提前起势另记为 `pre_roll_seconds`。

关键音画锚点包括：雨滴第 13 帧、回应路径第 540 帧、竹杖第 738 帧、草鞋第 804 帧、“谁怕”第 1,200 帧、蓑衣三次编织第 1,464／1,530／1,596 帧、归去轻杖第 3,046 帧、当下的一步第 3,112 帧、天气展开第 3,178 帧。详细 28 项事件表见 `public/audio/README-V2.md`。

BGM 保持原速原音高，处理仅包括整体配平、十处不到 0.8 dB 的短暂音量让位和结尾淡出。完整混音是 `soundtrack-v2.wav`：120 秒、48 kHz、双声道、24-bit PCM，共 5,760,000 个采样。`sfx-v2.wav` 是独立拟音轨；成片只播放完整混音，避免重复叠加。

PCM 报告记录整体响度 −15.0 LUFS、真峰值 −1.75 dBTP；这些是音频源文件的测量值。最终 MP4 中的 AAC 音频需要单独测量，结果以其对应的成片验证报告为准。

## 七、文字与思想边界

- 《定风波》是词。1082 年、黄州、沙湖道中遇雨用于历史背景；不虚构人物对话或心理独白。
- 原词与现代释意在版式、时段和角标中区分。“一时阴晴，一生辽阔”等现代标题不作为原词引用。
- 天气与路径承担思想隐喻，不给情绪、从容或幸福添加分数、科学函数或统计概率。
- “微冷”保留真实感受与自我照料；从容允许暂停与调整。
- 斜照表现境遇会变化，不承诺坚持必然成功；结尾让雨晴共存于更宽的人生视野。

## 八、复现与验证

安装依赖、预览、导出与浏览器设置见工程根目录 `README.md`。三维导出使用 `swangle` WebGL 后端；完整导出入口为 `npm run render`，主合成名为 `DingFengBoV2`。输出文件为 `out/dingfengbo-v2.mp4` 与 `out/cover-v2.png`。

验证目标包括：120 秒、1080p、30 fps、3,600 帧、H.264/AAC、完整音视频解码、响度与真峰值、MP4 快速起播布局、跳转播放及片尾音频淡出。导出脚本会运行 `scripts/verify-video.py` 并写出 `out/validation-v2.json`；播放与视觉检查需要结合实际导出的成片。只有具体文件的验证报告可以说明该文件的检查结果。
