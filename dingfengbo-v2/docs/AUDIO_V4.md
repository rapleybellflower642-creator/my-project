# V4 长片配乐与音效

字幕动画长片：594.267 秒，17828 帧，30 fps。没有新增旁白。

## 文件与重建

- 使用 `public/audio/soundtrack-v4.m4a`，其中已经包含完整配乐与少量音效。
- 用户上传《算力小曲》按字节保存为 `public/audio/bgm-v4-original.mp3`，SHA-256：`ab1ebad4e3ced73fa0d7763e455f573976c243ff0b00e0b7e91a90a4e3debd05`。
- 完整源曲解码长度 192.413792 秒，原速、原调连续循环；不先裁剪或改变源曲速度。
- 长 WAV 母带只保存在 `out/v4/soundtrack-v4.wav`。公开资产采用 AAC 256 kbps、48 kHz 双声道，避免超大文件进入仓库。
- 运行 `python scripts/audio_design_v4.py`。输入时间轴为 `public/v4/timeline.json`。时间轴未生成时脚本退出并提示，不进行等待轮询。
- 如需从上传源重新复制，可传 `--source /path/to/算力小曲.mp3`；脚本不会覆盖字节不同的既有源文件。

## 技术验证

- 音频逻辑长度严格对应 28524800 个 48 kHz 样本，与视频帧数对应。
- AAC 实测：**-15.05 LUFS / -1.67 dBTP**；完整解码通过，无解码样本削波。
- 开头淡入 0.3 秒，片尾淡出 2 秒；循环接缝采用 1 秒等功率交叉淡化。
- 37 处前景音效，仅选择部分章节、具体物件、动作与天气镜头；少量环境层低于音乐。不对每条字幕敲击。
- 所有音效由固定随机种子与原有合成函数产生，没有外部音效采样，也没有新增旁白。
- 母带按 -15 LUFS / -1.8 dBTP 目标进行两遍响度校准，交付 AAC 的实测指标如上；AAC 额外增益：0.000 dB。
- 片尾淡出前 2 秒检测窗口的 RMS 为 -18.08 dBFS，确认循环音乐持续至淡出。最后一段源曲从 574.241375 秒开始，精确覆盖至视频末尾。
- 量化报告在 `public/audio/audio-v4-report.json`；逐帧 cue 表在 `public/audio/audio-v4-cues.csv`。

当前完成的是技术指标、源文件与时间映射验证。**尚未进行主观听音或视听同步审查**；循环平滑度和音乐/音效听感仍需带声音预览确认。
