# 《定风波》V3 · 谁怕？

本轮交付：分镜与预览版。120 秒、16:9、30 fps；原配乐《算力小曲》保持原速原调；音乐、音效和中文字幕，无旁白。预览文件为 960×540；工程合成为 1920×1080。

## 这次改了什么

- 前 7 秒用“因诗入狱—被贬黄州—他凭什么说谁怕”建立悬念。
- 苏轼成为叙事主体：补入 1079 年乌台诗案、1080 年贬居黄州、躬耕东坡以及 1082 年沙湖遇雨。
- 先交代这个人的处境，再逐句讲出他的反应和我们今天可以怎样理解这首词。
- 画面增加诗稿、牢门、舟行黄州、田地、同伴避雨、人物行走、衣袖、斜照和回望。主体镜头内约 2.2 秒发生一次景别或动作变化，字幕保留阅读时间。
- 竹杖芒鞋的独立三维陈列从多个长段落缩至 2.2 秒；其余时间看见人物与环境。
- 指定右下角署名及片尾制作、配乐小字均删除。音乐来源、制作信息保留在工程文档。
- 重做音效时间轴，让案卷、牢门、江水、锄土、雨、脚步、衣袖和光的出现都有区别。

## 历史与阐释

词序记载：“三月七日，沙湖道中遇雨。雨具先去，同行皆狼狈，余独不觉。已而遂晴，故作此。”片中的日期按原词纪年，不把农历三月七日换成公历 3 月 7 日。

1079 年乌台诗案、1080 年贬居黄州和 1082 年遇雨以时间文字明确区分。人物、城郭与舟行是叙事插画，不是历史肖像、文书或路线的复原。实景中的行路人不穿蓑衣；“一蓑烟雨”按诗意理解。

“仕途得失不必决定此刻的心”等是结合生平的现代解读。原词与现代说明在字号、位置上分开，并以“可以这样读”提示阐释层次。

## 审阅入口

以下命令均在 `dingfengbo-v2/` 执行。需要 Node.js 22 或 24、npm、FFmpeg 和 Chromium；文件校验还需要 Python 3 与 FFprobe。已附带完整 WAV 混音，正常预览无需重新生成音频。

执行 `npm ci`、`npm run studio` 后，打开终端显示的地址，选择主合成 **DingFengBoV3**。Studio 使用端口 `3002`；**V3-Scenes** 中可逐段审阅。

| 命令 | 输出 |
|---|---|
| `npm run preview:v3` | `out/v3/dingfengbo-v3-preview.mp4`，960×540、30 fps、120 秒，含完整混音；同时生成关键帧与封面 |
| `npm run storyboard:v3` | `out/v3/frame-*.jpg` 与 `out/v3/cover.png`，不导出视频 |

预览脚本默认使用 `/usr/bin/chromium`，可用 `REMOTION_BROWSER_EXECUTABLE=/path/to/chromium npm run preview:v3` 指定浏览器。`out/v3/preview-render.mp4` 是无声渲染中间文件；供审阅的文件为合并音轨后的 `dingfengbo-v3-preview.mp4`。`npm run render`、`npm run cover` 和 `npm run review` 仍导向 V2。

完整预览生成后，可运行：

```bash
python3 scripts/verify-preview-v3.py
node scripts/check-preview-v3.cjs
```

报告分别写入 `out/v3/validation.json` 与 `out/v3/browser-check.json`；后者通过静音播放核验解码、跳转和画面，不能替代音效平衡与视听同步的主观审听。

若要从实际预览视频生成分镜总览，另安装 Python Pillow 并确保系统有 DejaVu Sans 字体，然后运行 `python3 scripts/storyboard-preview-v3.py`，输出 `out/v3/storyboard.jpg`。

源码入口：`src/v3/Film.tsx`（时间轴）、`src/v3/Scenes.tsx`（文案）、`src/v3/HistoryArt.tsx`（人物与历史场景）、`src/v3/JourneyArt.tsx`（行路与天气）、`src/v3/Frame.tsx`（排版）、`scripts/audio_design_v3.py`（声音）。音频重建和测量说明见 [AUDIO_V3.md](AUDIO_V3.md)。
