# 用户提供的原文（保留口误与重复，供对照）

当你身处逆境或是人生迷茫时，不妨读一读苏轼的《定风波》，莫听穿林打叶声。他被称为苏轼最值得反复品味和解读的一首词。而他的背后，只不过是一场小雨，却是苏轼用一生积累领悟出来，描写人生境界最高的一首词。我们总说太难了，熬不下去了。可人生哪有永远的晴天？我们这一生会遇到很多雨，是考试失利的雨，是失去工作的雨。当他们劈头盖脸的砸来，所有人都慌不择路时，我们到底该怎么办？

公元一零八二年，苏东坡四十五岁，这一年距离他乌台诗案被贬黄州已经过去三个年头。黄州不是什么好地方，偏远贫瘠。他名义上是团练副使，实则是被监视的罪犯，没有俸禄，没有权力，连像样的房子都住不起，只能自己在东坡开荒种地，自称东坡居士。从大宋顶流到如今的乡野。如今的乡野农夫，这是一个中年男人的人生谷底，这也是这首词的背景音。

这一天，三月七日，他跟朋友们在沙湖道上走着，突然下起了大雨。雨具先去，专门管带雨伞的仆人提前走了，结果同行皆狼狈。大雨袭来，所有人都慌了，抱头鼠窜，狼狈不堪。雨独不绝，只有我苏轼不觉得有什么，没有伞也没有躲，就在暴雨里走出了最从容的姿态。然后雨停了，天晴了，他写下了这首词。

莫听穿林打叶声，何妨吟啸且徐行。词的开头就是一句反常识的话，换做我们遇到穿林打叶的暴雨，第一反应肯定是快跑，别淋着。可苏轼却说莫听穿林打叶声是什么？是暴雨砸在树叶上的噼啪声，让人烦躁慌张。这还是雨吗？不，这是乌台。这是乌台诗案里那些政敌的构陷，那些小人的谗言，放在人生中就是上司的指责，旁人的闲言，生活的暴击。莫听不是真的没听见，而是不往心里去。这些噪音你可以让他穿耳过，但你绝不能让他入心。你一入心就输了。就像你在网上看到恶意评论，与其气得发抖，不如关掉页面。不是怕了，而是懒得让他消耗自己。

然后呢？何妨吟啸且徐行？何妨有什么关系呢？这两个字太妙了，带着点无所谓的洒脱。吟啸，这是古人最高级别的酷。吟是低声哼唱，啸是放声长啸。你可以想象他一边淋着雨，一边哼着歌，甚至在啊啊啊的长啸。且徐行，而且还要慢慢走，下雨而已，有什么关系呢？我不仅不跑，还能一边吟诗一边慢慢走。你越想让我慌，我偏不慌。你越想让我狼。越想让我狼狈，我偏要优雅。这不是装出来的潇洒，是真的想通了。他知道雨总会停，慌也没用。就像人生的难关，再急也得一步一步过。与其狼狈逃窜，不如稳住脚步，还能顺便看看雨景。你看那些真正厉害的人，遇到事从来不是慌慌张张的，不是他们不会怕，而是他们懂得越乱越容易出错，稳住心神才是最要紧的。

然后他低头看了看自己的装备：竹杖、芒鞋、青胜马。竹子做的拐杖，草编的鞋子，多么简陋啊！这是流放者的标配，是穷人的装备。马是富贵的象征，是他当大官时的座驾。可苏轼却说青胜马。我现在这套穷装备比骑马轻快多了。为什么？因为下雨天骑马，马蹄会陷进泥里，马会打滑，骑马的人要担心马受惊，要顾及体面，反而不自由。而他拄着竹杖穿。拄着竹杖，穿着草鞋，什么都不用怕，脚下轻，心里更轻。这就是苏轼最通透的地方。人之所以累，往往是被体面、身份绑住了。就像有人明明工资不高，却非要买名牌包撑场面；明明一堆借款，却非要硬着头皮买车买房。这些马鞍压的人喘不过气，倒不如竹杖芒鞋来的自在。

于是他轻蔑的向这场暴雨，向他的命运，甩出了两个字：谁怕？怕什么？怕下雨？怕落魄？还是怕别人笑话？这是全篇最硬的两个字，是骨子里的不服输。然后是他硬核的人生宣言：一蓑烟雨任平生。一蓑烟雨不再是眼前的这场雨了，而是概括了他这辈子经历的所有风雨、科举的波折、官场的倾轧、被贬的屈辱。他说这些风雨我全接了，任平生，这辈子我就这么坦然受着了。这句话直接封神。直接封神，他不是在说求求你别下了，也不是在说等雨停了我就好了，他在说下吧，随便下。我这一辈子就打算在风雨里过了。他接受了苦难，还把苦难当成了日常。这不是破罐子破摔，是接纳，接纳人生有晴有雨，接纳自己有顺有逆，不再和命运较劲，反而有了和生活周旋的力量。就像有人失业后不怨天尤人，而是坦然去摆地摊做兼职，接受了风雨，反而能在风雨里站稳脚跟。当一个人连苦难本身都不再畏惧时，这世上还有什么能打败他呢？

词的下半部分写的是雨停之后，料峭春风吹酒醒。雨后的春风有点凉，把他身上的酒意吹醒了，也让他从刚才的洒脱里多了一丝清醒的感知。微冷，这里的微冷特别真实。他不是神，他是人，他也会冷，会怕，会迷茫。这会迷茫，这才是真实的人生。哪有永远的热血沸腾？总有一些时候，我们会觉得疲惫，觉得凉。这是全篇最真实、最脆弱的人性时刻。

但重点在后面，山头斜照却相迎。就在他觉得有点冷的时候，抬头一看，山头上的夕阳正对着他照过来，暖融融的。你看，人生就是这样啊，它不会一直下雨，也不会一直寒冷。刚才还是瓢泼大雨，转眼就有夕阳；刚才还是狼狈不堪，转眼就有温暖相迎。很多时候，我们觉得熬不下去了，其实再撑一下，就会看到斜阳。就像你熬夜赶项目，觉得快崩溃时，同事递来一杯热咖啡；就像你为钱发愁时，突然收到一笔意外的收入。那些不经意的温暖，总在你觉得微冷的时候出现。

雨停了，天晴了，太阳也出来了。按理说，苏轼应该很高兴吧？不，如果他这么。如果他这么想，他就不是苏东坡了。他写下了全篇的结尾，也是哲学的终极。回首向来萧瑟处，他回头看了一眼刚才淋雨的地方。这个回首，他看的不只是来时的路，是他那半辈子的风风雨雨，是那座乌台诗案的监狱。然后他说了两个字：归去。这两个字不是说回家，是放下，放下刚才的雨，放下刚才的冷，放下那些让他纠结的过往。然后得出了那句震古烁今的结论：也无风雨，也无晴。这是全篇的最高境界。这是禅。他在说，风雨晴天对我来说已经没有区别了。当你回头看的时候，那些曾经让你痛苦的风雨和让你开心的晴天都成了过去式。他们不再能左右你的情绪，不再能定义你的现在。就像你现在回头看，上学时为一次考试不及格哭鼻子，工作后为一次被后为此被批评而失眠，当时觉得天塌下来的事，现在是不是都觉得没什么大不了？这不是麻木，是通透。

苏轼写这首词的时候，正是他人生最落魄的时候，可他没有抱怨，没有沉沦，他知道人生就是一场体验，好的坏的都会过去。我们要做的不是纠结于过去的风雨，而是好好走脚下的路。这就是《定风波》的力量。他告诉我们，人生的底气从来不是来自顺风顺水，而是来自于风雨中也能徐行的从容，来自于接纳一切的通透。这篇《定风波》没有一句写豁达，却句句都是豁达。他让我们明白，人生的风波是定不住的，它总会来。我们唯一能定住的是那颗就算淋着雨也要慢慢走的心。下次再遇到穿林打叶的风雨时，不妨想想苏轼，想想这首《定风波》，然后告诉自己没什么大不了的，慢慢来，雨会停。来，雨会停，夕阳会来，而我们只管稳住脚步，好好走下去。
