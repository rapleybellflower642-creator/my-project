# 《定风波》V3 黑金图解版

根据用户提供的《运气的形状》两张分镜参考重建视觉表达：黑色空间、暖金文字、真实三维物件、线条与图形随叙事展开。内容仍是苏轼《定风波》，全片120秒、1920×1080、30fps，字幕＋动画＋《算力小曲》＋音效，无旁白。

## 画面如何讲述

- 黄铜官印落下，引出“跌到谷底，他为何不慌”；卷轴承接片名。
- 1079年案卷、1080年黄州、1081年躬耕与1082年沙湖遇雨连成写作背景。官衔和实权之间的线断开，土地在落锄、播种之后逐渐长出新芽。
- 遇雨以分流的路线表示同行慌乱与苏轼徐行；“莫听”以穿过空间又消散的声波表达；“何妨”伴随逐次出现的步点展开。
- 竹杖芒鞋只用约2秒独立物件镜头，随后转为身份执着与轻盈金线的对照。
- “谁怕”单独落定，“一蓑烟雨任平生”进入承受风雨的空间；酒盏、冷风与越过山脊的斜阳承接情绪变化。
- 回首把来路展开为三个经历节点，节点退暗，前方金线继续；片尾收束到“也无风雨，也无晴”。

图形用于解释词意，不是量化情绪的统计图。雨中同行光点不表示有确切史料记载的同行人数。物件是为影片原创建模的示意，不冒充文物复原。

画面无角落署名、制作或配乐小字；片尾仅保留作品题名。参考图中的主题、正文、英文装饰与品牌署名未搬入影片。

## 编辑和导出

在 `dingfengbo-v2/` 中运行：

```bash
npm ci
npm run typecheck
npm run studio
```

选择 **DingFengBoV3Gold**。13个章节在 **V3-Black-Gold** 中可独立预览，封面为 **CoverV3Gold**。

```bash
node scripts/v3g/prepare.cjs
node scripts/v3g/render.cjs --stills 1.8,5.7,9.8,21.5,30,39,50,59,68,79,88,97,107,117.5
node scripts/v3g/render.cjs --sample --jobs 3
node scripts/v3g/render.cjs --full --jobs 3
python3 scripts/v3g/verify.py
node scripts/v3g/check-playback.cjs
python3 scripts/v3g/storyboard.py
```

已附所需物件序列和最终音频，正常编辑和导出无需重建它们。三维建模脚本位于 `scripts/v3g/`；音乐重建脚本为 `scripts/v3g/audio.py`。依赖、缓存和原生SVG导出说明见 [渲染说明](RENDER.md)。

可编辑时间轴为 `src/v3g/Film.tsx`，各章节在 `src/v3g/scenes/`，字幕记录为 `src/v3g/timeline.ts`。Studio与正式导出使用同一个 `FrameSvg` 场景函数，导出器内联本地PNG和字体后逐帧栅格化。

## 声音与检查

原曲前120秒保持原速原调，原文件长约192秒，所以本版无须接入第二次循环。音效只放在叙事动作和关键词处，不逐字敲击。[声音制作说明](AUDIO.md)包含25个事件及原曲起音分析。

完整视频固定为3600帧。交付目录附全片解码、音轨指标、浏览器播放、输入摘要和逐段重复帧统计。技术检查不代替主观试听；最终分镜图均从实际交付MP4中提取。
