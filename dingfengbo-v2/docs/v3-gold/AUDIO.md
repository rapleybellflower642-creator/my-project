# 黑金版《定风波》音频

成品为 `public/audio/soundtrack-v3g.m4a`，120 秒，48 kHz 双声道 AAC LC，目标码率 256 kb/s；无旁白。原曲仍使用最新上传的 `public/audio/bgm-v4-original.mp3`，取 **0–120 秒，原速、原调、无循环、无音乐段落重排**。所有声效为本地合成，旧版本与原曲文件保持不变。

最终AAC编码后测得 **−15.08 LUFS、−1.64 dBTP**，达到目标−15 LUFS（允许±1）与true peak≤−1 dBTP。实际归一化模式为dynamic。格式探测时长严格为120.000000秒；三个原曲时间对齐抽检窗口的相关峰延迟均为0采样、相关系数均大于0.9993。

## 动态与结尾

开头保留原曲前0.4秒的低电平，第一乐句轻起，2.4秒达到主增益。“谁怕”前的音乐在 **73.52–74.066667秒**短暂下压，最低相对增益为0.68（约−3.35 dB），最低电平保持0.13秒；在关键词进入时恢复，没有插入静音。后段逐渐放松密度，**118.6–120.0秒淡出1.4秒**。

音乐先做增益包络，与合成材质声混合，再进行最终响度归一化及AAC编码。实际归一化模式和编码后响度均记录在JSON中，避免把最终处理误称为仅线性增益。

## 复现与检查

在 `dingfengbo-v2/` 目录运行：

```bash
python3 scripts/v3g/audio.py
```

依赖环境已安装的 NumPy、SciPy、FFmpeg 与 ffprobe。临时PCM放在`/tmp`，构建结束自动清理。生成：

- `public/audio/soundtrack-v3g.m4a`
- `public/audio/audio-v3g-report.json`
- `public/audio/audio-v3g-cues.csv`（UTF-8、LF换行）

构建自动验证AAC前120秒的解码长度为5,760,000个双声道采样帧，并检查有限波形值、48 kHz双声道、源SHA不变、响度、true peak和CSV换行；另在9、66、114秒各抽取2秒，与原曲对应时刻做相关校验，对齐允许±1采样，本次实测均为0采样。AAC的256 kb/s为编码目标，实际平均码率可轻微浮动。
