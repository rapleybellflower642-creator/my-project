# V3 音效设计与验收记录

本版与新的 120 秒叙事剪辑配套：苏轼的案卷、牢门、渡江、耕作、雨中同行、吟啸徐行、微冷与斜照使用各自的材质声音。开头的三次变化对应 13 / 79 / 145 帧，主段“谁怕”在 1991 帧获得全片最明确的低频落点。

## 使用与重建

- 成片只播放 `public/audio/soundtrack-v3.wav`；其中已经包含音乐与音效，不能再叠加独立 SFX 轨。
- `public/audio/sfx-v3.wav` 是仅音效的审听/重混轨。
- `public/audio/audio-v3-report.json` 保存响度、样本映射、原曲哈希、所有 cue 和测量结果。
- `public/audio/audio-v3-cues.csv` 提供可导入编辑器的 cue 表。
- 在项目目录运行 `python scripts/audio_design_v3.py`。需要 Python、NumPy、SciPy、FFmpeg；当前云机器均已提供。
- 随机种子固定为 `10822334`，复用 `scripts/audio_design_v2.py` 的合成函数，V2 源文件未改动。

## 音乐与节奏

原始 `bgm-original.mp3` 前 120 秒从起点连续取用，保持原速、原调，没有旁白或外部采样音效。音乐只做增益、10 个重点落点的短暂闪避和结尾淡出；最大闪避约 1.21 dB。总线归一化验证采用 linear 模式。

全片 36 个前景音效 cue，外加 7 段很低的场景底音。音效材质包括纸张、木门/门闩、江水、土壤、草纤维、脚步、竹杖、雨叶、衣袖和空气。竹杖与芒鞋的两个近景音效限定在 1727 / 1760 帧，1793 帧即转回人物衣袖，1840 帧使用纸张作词意转场。

后半段逐步降低冲击感。3309 帧之后不再添加前景 cue；3442 帧进入片尾时音效轨已经静音；118.6–120 秒使用余弦平方淡出，最后一个样本为零。

## 技术验证

- 两条 WAV 均为 120.000 秒、48 kHz、24 bit、双声道，共 5,760,000 样本。
- 混音综合响度：**-15.00 LUFS**；真峰值：**-1.73 dBTP**；LRA：**1.8 LU**。
- 独立音效轨综合响度：**-28.51 LUFS**；真峰值：**-9.75 dBTP**。相较 V2 的 -31.02 LUFS，前景材质更明确。
- 无削波，末样本为零；原曲文件哈希未变，音乐样本映射误差小于 `2e-7`。
- 完整脚本连续运行两次，混音 WAV、音效 WAV 的 SHA-256 均一致；片尾 3442–3600 帧的音效轨验证为全零。
- 帧与样本映射在 30 fps 下为每帧 1,600 个样本。少量纸张、衣袖和空气 cue 在目标帧前开始，用于自然的动作准备；见下表的预卷列。

本记录验证的是技术指标、确定性生成和指定剪辑帧点的映射。**尚未完成主观听音或视听同步审查**；cue 来自编辑节奏表，不能仅凭样本位置宣称与音乐听感完美卡点。需要在 Studio 中带声音播放以确认实际平衡与画面接触时刻。
