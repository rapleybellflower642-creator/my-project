# V3 重制音频

成品：`public/audio/soundtrack-v3r.m4a`，120.000 秒，48 kHz、双声道、AAC LC，编码目标 256 kb/s。AAC 成品复测 **−15.08 LUFS、−1.81 dBTP**，达到 −15 LUFS（±0.25）与 true peak ≤ −1 dBTP 的要求。没有旁白。

原曲使用 `public/audio/bgm-v4-original.mp3` 的 **0–120 秒，原速、原调、无循环、无重排**。MP3 容器完整时长为 192.456 秒，完整解码为 192.413792 秒；两者差异来自 MP3 编码延迟／填充的容器计时。源文件 SHA-256：

```text
ab1ebad4e3ced73fa0d7763e455f573976c243ff0b00e0b7e91a90a4e3debd05
```

源文件保持不变。仅进行音乐增益包络、合成音效混合、响度归一化和 AAC 编码。10、62、114 秒处各取 2 秒比较成品与对应原曲，零时差相关系数分别为 0.999822、0.999389、0.999628，相关峰延迟均为 0 个采样；这些抽检支持时间映射保持不变。

## 原曲起音与剪辑锚点

分析使用 24 kHz 单声道副本，1024 点 Hann STFT、120 采样 hop（5 ms），把 45–9500 Hz 正向对数谱通量与 45–260 Hz 低频通量按 65%／35% 混合；随后用自相关和稳健周期拟合得到候选节奏。

原曲约 0.40 秒才越过 −60 dBFS 的 10 ms RMS 阈值，首个明显谱起音为 **0.405 秒**。保留这段自然轻起，不将音频前移。拟合主脉冲候选约 **109.167 BPM**，细分约 **0.274807 秒**，拟合中位误差约 3.5 ms。自动分析存在半拍、倍拍与三连音层级歧义，不能把它直接等同于经过听辨确认的拍号。

## 配器和动态

共 **26 处**精选合成音效，另有 5 段很低电平、渐入渐出的环境底声。材质包括纸页、木门与小门闩、木柄与碎土、舟水、雨叶、湿草鞋、竹杖、衣袖、冷风和暖风。全部为固定随机种子生成，复用旧版未改动的合成函数；无外部音效素材。不同动作使用不同材质，步声只挑前景接触，不逐拍重复敲击。

音乐开头轻起，在 2.4 秒达到主增益。“谁怕”前 67.98–68.5667 秒短暂下压，最低相对增益 0.64（约 −3.88 dB），最低电平仅保持 0.12 秒，在关键词落点完整恢复；没有插入静音。后段缓慢减轻音乐密度，111 秒起片尾继续保留原曲，**118.6–120.0 秒完整淡出 1.4 秒**。

## 生成与验证

在项目根目录运行：

```bash
python3 scripts/v3r/audio.py
```

依赖为环境已装的 Python、NumPy、SciPy、FFmpeg、ffprobe。临时 PCM 写入 `/tmp` 并自动清理。脚本只生成新版 AAC、JSON 报告和 CSV，不改原曲或旧版音频。

完整数据见：

- `public/audio/audio-v3r-report.json`：原曲与成品 SHA、完整时长、原速无循环说明、分析方式、候选起音、26 个 cue、动态包络、响度与峰值、格式和时间对齐抽检。
- `public/audio/audio-v3r-cues.csv`：逐 cue 精确帧、采样、音色、增益、声像和同步依据；UTF-8，**LF 换行**。

脚本自动检查 AAC 前 120 秒解码长度为 5,760,000 个双声道采样帧、所有值有限、48 kHz 双声道、容器时长 120 秒、原曲 SHA 不变、成品响度与 true peak、时间对齐误差不超过 1 个采样（本次实测为 0），以及 CSV 无 CR。AAC 使用目标码率控制，探测到的平均码率允许围绕 256 kb/s 浮动。

这些是已执行的客观检查。**本音频构建未进行主观试听，也未宣称耳机听感或最终声画同步回放已通过**；最终成片仍应按表中的接触帧做视听复核。
