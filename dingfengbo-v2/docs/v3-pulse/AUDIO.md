# V3 Pulse：剪辑节奏与音频

成品 `public/audio/soundtrack-v3p.m4a`：**120.000000秒、48 kHz双声道AAC LC、目标256 kb/s**。编码后实测 **−15.07 LUFS、−1.89 dBTP**，满足−15 LUFS（±1）与true peak≤−1 dBTP。无旁白。

这版把52镜头剪辑表与48处声音事件绑定：**3处主冲击、13处材质接触、4处细节、28处轻纹理**。38处cue直接落在构图切点，10处按画面实际接触帧定位。主体节奏来自原曲，铜印、纸、泥土、种子、雨叶、草鞋、竹杖、绳线、陶杯与风使用不同音色；没有把所有切镜处理成相同重击。

## 音乐来源与分析局限

使用最新上传的 `public/audio/bgm-v4-original.mp3` **前0–120秒，原速、原调，无循环、无段落重排**。原曲容器完整时长192.456秒，解码完整时长192.413792秒，时长足够，无需循环。源SHA-256：

```text
ab1ebad4e3ced73fa0d7763e455f573976c243ff0b00e0b7e91a90a4e3debd05
```

分析仅把副本转成24 kHz单声道；使用1024点Hann STFT、120采样hop（5 ms），将45–9500 Hz正向对数谱通量与45–260 Hz低频通量按65%／35%混合，检测局部起音，再参考自相关与稳健周期拟合。主脉冲候选约109.167 BPM、细分间隔约0.274807秒。实际切点来自检测到的起音，不靠把单一BPM无限外推。

11–17秒的原曲攻击较弱且不如其他段落规则，此处仍选择真实局部起音。谱起音只能说明能量变化，不能自动确认拍号、乐理下拍或主观听感。**没有把自动检测宣称为人工听音通过。**

## 动态与输出检查

开头保留原曲自然低电平，但音乐在**0.65秒**即达到主增益。高潮前仅在**73.72–74.066667秒**短暂下压，最低相对增益0.72（约−2.85 dB），最低电平保持0.09秒，“谁怕”切入时恢复。没有插入静音。结尾严格在**118.6–120.0秒淡出1.4秒**。

处理顺序是音乐增益包络、合成材质混合、最终响度归一化、AAC编码；实际归一化模式为dynamic。所有旧版本和原曲文件保持不变。AAC目标码率256 kb/s，实际流平均码率263285 b/s。

构建自动确认：120秒、5,760,000个双声道采样帧、48 kHz双声道、有限波形值、原曲SHA不变、剪辑表SHA绑定、响度和true peak达标、CSV无CR。10、56、114秒各2秒与原曲对应窗口的相关峰延迟均为0采样，相关系数均大于0.9991，支持时间映射未改变。

## 复现

```bash
python3 scripts/v3p/audio.py
```

依赖已安装的NumPy、SciPy、FFmpeg、ffprobe。脚本读取冻结的`public/v3p/edit-grid.json`，临时PCM写入`/tmp`并自动清理，生成新版AAC、`public/audio/audio-v3p-report.json`与`public/audio/audio-v3p-cues.csv`。CSV为UTF-8、LF换行，按帧排序。

报告包含每个cue的镜头ID、切点偏移、同步依据、力度档位、音色、声像、原曲和成品SHA、编码后响度及时间对齐抽检。**本音频构建没有进行主观试听，也没有宣称最终声画回放已经通过；成片仍需按实际画面复核。**
