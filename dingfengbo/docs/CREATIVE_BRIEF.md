# 《定风波》两分钟动画优化方案

本次交付为创意与制作方案，未开始制作新成片。参考材料为用户上传的《沉没成本.txt》《算力小曲.mp3》以及仓库中的旧视频；参考提示词中的“直接制作”等指令不作为本次执行要求。

## 1. 创意定位

片名：**《定风波：风雨有时，脚步由你》**。

主题：在人生无法完全掌控的境遇里，找回自己的步调；承认真实的难受，也容得下顺境与逆境。

以一个雨中行路人的连续旅程贯穿全片：骤雨扰心 → 稳住脚步 → 承认微冷 → 接住暖意 → 回望来路 → 安放阴晴。哲理由动作、环境和诗句共同呈现。

苏轼《定风波·莫听穿林打叶声》的体裁是词。背景交代为“1082年，黄州。沙湖道中遇雨”，只占一个短段落。人物采用宋代行路人的意象，不声称复原苏轼的真实容貌。

延续原片的纯音乐＋中文文字叙事，不添加人声旁白。精确120秒，16:9，1920×1080，30fps，共3600帧。

## 2. 旧方案的改进方向

抽帧可见旧片长时间使用相近的暗底、暖金线条、小型中心图示，景别与明暗变化较少；参考提示词也没有独立音效层的设计。

本片以完整环境、贯穿人物、明确动作和光色变化增加丰富度。一个动作产生下一个画面：水滴形成涟漪，涟漪带出山路；竹杖点地带动视角；衣袂遮挡完成转场；人物回首时镜头才转向来路。图像之间形成因果联系。

加快的是有效动作和视角变化。文字继续保留充分阅读时间，避免诗句、解读和额外底部字幕三层同时堆叠。

## 3. 视觉与配色

风格：**宋画的色彩与留白、纸本矿物质感、现代电影镜头、2.5D分层动画**。人物以背影、侧影和局部为主，空间至少包含前景枝叶、中景人物、远景山林三个层次。纸纹轻微稳定，雨、雾、衣袂与光影具有不同运动速度。

| 色彩 | 色值 | 用途 |
|---|---|---|
| 深墨青 | `#173C40` | 雨林、树影、人物轮廓；保持暗部细节 |
| 雾青灰 | `#799693` | 远山、雨雾、空间过渡 |
| 宣纸白 | `#E9E4D8` | 留白、标题、浅色场景 |
| 朱砂 | `#B8553B` | 小印章、极少数关键词点色，约占画面1%–3% |
| 暖日色 | `#D7B576` | 斜照、湿地反光、后段局部亮部 |

色彩随叙事变化：0–60秒以墨青与雾青为主；60–79秒从微冷过渡到局部暖光；79–106秒提亮纸色、降低饱和度；106–120秒让青色山林与暖色斜照保持平衡。暖光是被感受到的片刻，不代表人生从此没有困境。

标题与诗句使用本地思源宋体／Noto Serif CJK SC；现代解读使用本地思源黑体／Noto Sans CJK SC。标题建议100–140px，诗句64–88px，解读48–60px，背景信息32–36px，依具体字数调整。画面安全边距至少96px。文字避开枝叶、雨线和高对比纹理；优先安排在自然留白处。

原词引用与现代解读明确区分。诗句先出现，解读后出现或替换诗句；普通单屏正文控制在10–24字，较长句分两行。大多数文字稳定显示3–5秒，整句以阅读测试为准。全片仅使用下列文案，不另叠一套重复字幕。

## 4. 音乐与节奏

上传的MP3时长约192.456秒。本方案使用前120秒，保持原速，最后1.4秒渐弱。

本次对前120秒音频进行了节奏与能量分析，主节拍估计约109.18 BPM，每拍约0.550秒，四拍约2.198秒。数值是分析估计，不声称首拍位置已精确确认到帧。

窗口能量与瞬态分析支持参考提示词中的段落走向：约18秒增强；约88–106秒收敛；约106秒重新增强。最终制作时再用波形与试听校正具体切点，以下时间为叙事分配，不要求每个边界恰好是强拍。

节奏规则：

- 主要动作利用半拍、1拍或2拍完成；物体重心变化、脚步落地和关键字落定贴拍。
- 活跃段每2–4拍出现一次有效动作、视角或空间变化；完整构图通常维持4–8拍，让文字可以读完。
- 全片目标约30–36次有效视角／构图变化，其中包含同一场景内推进、跟拍和焦点转移，无需全部硬切。
- 约88–106秒主动减少运动与音效，让回望拥有空间；106秒后的鼓组回归支撑最终诗句。
- 人物姿态与步调保持从容。较快节奏由剪辑、环境和动作细节承担，人物不奔跑。

## 5. 完整120秒分镜与文案

下表文案按斜线或箭头先后出现。诗句与解读分时呈现，不要求所有文字同时上屏。

| 时间 | 屏幕文字 | 画面与动作 | 音效设计 |
|---|---|---|---|
| 00:00–00:06 | **如果人生的雨，／迟迟不停呢？** | 雨滴击中叶面；落入水洼；草鞋踏入画面。以三个近景迅速建立困境，最后露出行路人的背影。 | 一枚近处水滴、短促雨声、一声踩水。音乐从0秒开始。 |
| 00:06–00:15 | **1082年，黄州。／苏轼在沙湖道上，遇见一场雨。** → **《定风波》** | 镜头沿山路后退，前景枝叶掠过，人物进入青绿山林。题名落在右侧雾气留白中；取消满屏装饰性标签。 | 风穿竹叶；题名落定配轻木响。 |

| 00:33–00:42 | **竹杖芒鞋轻胜马。** → **手里的东西不多，／也可以走得自在。** | 竹杖、草鞋、蓑衣做三次局部匹配剪辑；最后拉开为疏朗长路。质感来自竹节、草编与湿润路面的细节。 | 竹节轻触、草鞋擦地，与原鼓组留出空隙。 |

| 01:10–01:19 | **山头斜照却相迎。** → **好的时候，尽情感受。／坏的时候，慢慢经过。** | 一束暖光落上山脊，随后照到人物肩头和湿地。变化从局部发生，保留远山的青色。 | 风声变轻，辅以很短的清亮泛音；避免堆叠悦耳提示声。 |

## 6. 动画设计的具体要求

用六种运动形成变化：雨滴与涟漪、人物行走、衣袂与蓑衣反应、前中远景视差、遮挡与匹配剪辑、光照随空间流动。

至少安排三个具有记忆点的镜头：

1. 开场雨滴—涟漪—草鞋的连续动作，让观众马上进入现场。
2. “谁怕？”的大字退让与人物跨水同步发生，形成情绪抬升。
3. 结尾镜头升高，人物变小、道路变长、阴晴共存，把视野从一次遭遇扩展到一段人生。

至少安排三次景别对照：近处叶面与远处山路；蓑衣雨珠与烟雨全景；拢衣的局部动作与最后的开阔空间。相邻段落不连续重复同一种“中央图形＋整齐文字”的结构。

文字入场使用短遮罩、轻位移或整体显现，建议6–10帧完成，随后稳定。书写效果主要用于片名或个别短字，长句不逐字慢写。镜头运动不会将正在阅读的文字带出安全区。随机雨线固定种子，分层运动避免背景静止而只让文字出现。

## 7. 声音设计

建立三层声音：原BGM承担音乐节奏；风、雨、水声承担环境连续性；脚步、竹杖、衣料承担动作触感。

全片约12–18个有意识突出的音效事件，其余作为轻环境底声。雨滴和脚步不必每拍都响。音效密度主要集中在开场、18秒后、42秒“谁怕”和106秒结尾展开；88–106秒明显减法。

环境声始终退后，关键瞬态能辨识但不惊跳；先减少与原曲鼓点冲突的音效，再考虑短暂自动化降低BGM。避免长混响覆盖阅读停顿。配乐不变速、不改音高。

素材使用具备相应使用权限的拟音，或自行合成／录制的声音；保留来源说明。混合后的目标参考为约-16至-14 LUFS、真峰值不高于-1 dBTP，最终以实际听感、无削波和弱音可辨为准。耳机、普通扬声器和单声道折叠均需试听。

## 8. 内容准确性与验收

完整词句按原作顺序组织；原词与现代解读在字体、出现时机上区分，现代文案不署名为苏轼原话。“一边不安，一边向前”等属于创作者面向当代的解读，不当作对苏轼当时心理的史实判断。

“微冷”明确承认真实感受。“也无风雨也无晴”体现对顺逆的安放，不渲染麻木，也不承诺坚持以后必然成功或永远放晴。情绪重点放在可采取的脚步、可感受的温暖和对境遇的接纳。

制作时可沿用Remotion的分场景组件、帧驱动动画与本地中文字体。相邻场景共用同一行路人和环境系统，保证人物、光线与空间连贯。参考时间分配总计3600帧；最终卡点调整需保持总长120秒。

后续成片验收：

- 120秒、1920×1080、30fps；H.264／AAC；音视频完整解码。
- 全部文字可读，诗句无误字；文字、人物与前景不互相遮挡。
- 0–6秒进入主题，18秒左右明显推进，88–106秒收敛，106秒后完成情绪展开。
- “微冷”段能辨识拢衣与风感；最终从容能通过人物的稳定步调感受到。
- 音效与画面一致、关键落点贴拍、总混音不削波，末尾音效不截断。
- 后续制作交付应包括MP4、封面、可编辑工程及素材来源说明。本次文件仅为优化方案。
