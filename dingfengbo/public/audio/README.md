# 《定风波》声音工程

成片直接使用 `soundtrack.wav` 一条最终声轨；其内已含 BGM、环境声和拟音，请勿再次叠加 BGM。

## 文件

- `soundtrack.wav`：最终混音，精确 120 秒、48 kHz、24 bit PCM、立体声。
- `sfx.wav`：同长度的独立环境／拟音层，已含尾部淡出，不含音乐。
- `bgm-original.mp3`：用户上传的《算力小曲》原文件，保持原样。文件 SHA-256 与测量结果见 `audio-report.json`。
- `audio-report.json`：最终响度、真峰值、采样数、单声道兼容性指标及事件表。
- `../../scripts/audio_design.py`：从确定种子的噪声、阻尼振动和包络生成声音的可复现脚本。

音乐使用原文件前 120 秒，原速、原音高；只施加混音增益、四处最多约 0.6 dB 的极短音量让位和 118.6–120 秒尾部淡出。最后一个采样为零，尾音不会硬截断。

所有雨、风、水滴、竹杖、脚步、蓑衣、衣料、低频和空间扩展音均由本项目原创合成，未下载或调用第三方音效。暖光的泛音以原曲约 70 秒处实际频谱中的 606 / 908 / 1213 Hz 附近频率为基础，短暂、低位混合，不另加旋律。背景细雨采用不规则间隔的随机微水滴和带通噪声；动作声以低音量扩散反射建立空间，避免长混响覆盖文字停留段。

BGM 来源为用户提供的文件；本工程没有另外核验该音乐的第三方版权归属或许可范围。原创合成音效不包含其他人的采样素材。

## 复现

要求 Python 3、NumPy、SciPy、FFmpeg / FFprobe。原曲已复制到本目录时，在工程根目录执行：

```bash
python scripts/audio_design.py
```

或显式指定原始 MP3 路径：

```bash
python scripts/audio_design.py --bgm '/path/to/算力小曲.mp3'
```

生成器使用固定种子 `10820307`。响度采用 FFmpeg `loudnorm` 两遍测量处理，目标 -15 LUFS、真峰值上限 -1.3 dBTP，再以实际成品复测。脚本会断言 5,760,000 个立体声采样帧、48 kHz、120 秒、-15.5 至 -14.5 LUFS、真峰值不高于 -1 dBTP，且无削波。

工程验证包括 PCM 完整解码、实际整段响度和真峰值测量、尾采样检查及单声道折叠能量／立体声相关性检查。未把这些客观检测描述为人工耳机或扬声器试听。

本次最终实测：PCM 为 **-15.00 LUFS / -1.40 dBTP**，LRA 为 1.8 LU，无削波，立体声相关性为 0.675，最后一个采样值为零。独立拟音层为 -37.29 LUFS，主要瞬态真峰值为 -12.99 dBTP。另以 FFmpeg AAC-LC 320 kb/s 编码并重新解码核验，得到 **-15.04 LUFS / -1.60 dBTP**，编码后仍有足够余量。成片建议使用 AAC-LC 320 kb/s。
